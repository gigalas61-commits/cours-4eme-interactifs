Rappels sur les nombres relatifs

Nombre relatif : Un nombre relatif est un nombre qui possede un signe (+ ou -) et une partie numerique (sa distance a zero). Les nombres positifs sont a droite de 0 sur la droite graduee, les negatifs a gauche.

En 4eme, on apprend a effectuer les quatre operations (addition, soustraction, multiplication, division) sur ces nombres. Mais d'abord, revoyons les bases.

La droite graduee

Sur une droite graduee, chaque nombre relatif correspond a un point unique. Le nombre 0 est l'origine de la droite. Les nombres positifs se trouvent a droite de l'origine, et les negatifs a gauche.

Exercice interactif : Cliquez sur la droite graduee pour placer le nombre demande.

Oppose d'un nombre

Oppose : L'oppose d'un nombre a est le nombre -a. Deux nombres opposes ont la meme distance a 0 mais des signes contraires. Leur somme vaut toujours 0.
L'oppose de (+5) est (-5), car (+5) + (-5) = 0.
L'oppose de (-3) est (+3), car (-3) + (+3) = 0.
L'oppose de 0 est 0 lui-meme.

Valeur absolue

Valeur absolue : La valeur absolue d'un nombre relatif est sa distance a zero sur la droite graduee. On la note |a|. Elle est toujours positive ou nulle.
|+7| = 7  ;  |-4| = 4  ;  |0| = 0
|-15| = 15  ;  |+2,5| = 2,5

Comparer des nombres relatifs

Sur la droite graduee, un nombre est plus grand qu'un autre s'il est situe plus a droite. Tout nombre positif est plus grand que tout nombre negatif.
+3 > -5  (le positif est toujours plus grand que le negatif)
-2 > -7  (parmi deux negatifs, le plus proche de 0 est le plus grand)
-1 < 0 < +1

Addition de nombres relatifs

Regle 1 : Meme signe

Pour additionner deux nombres de meme signe, on additionne leurs valeurs absolues et on garde le signe commun.
(+3) + (+5) = +8  (meme signe + : on additionne 3+5=8, signe +)
(-4) + (-7) = -11  (meme signe - : on additionne 4+7=11, signe -)

Regle 2 : Signes contraires

Pour additionner deux nombres de signes contraires, on soustrait la plus petite valeur absolue de la plus grande, et on prend le signe de celui qui a la plus grande valeur absolue.
(+8) + (-3) = +5  (|8| > |3|, signe de 8 : +, et 8-3=5)
(-9) + (+4) = -5  (|9| > |4|, signe de -9 : -, et 9-4=5)
Pour calculer une addition de relatifs :
1. Comparer les signes des deux nombres.
2. Si meme signe : additionner les valeurs absolues, garder le signe commun.
3. Si signes contraires : soustraire les valeurs absolues (grande - petite), prendre le signe du nombre ayant la plus grande valeur absolue.
Ne pas confondre le signe de l'operation (+) et le signe du nombre. Dans (+5) + (-3), le premier + est le signe du nombre 5, le second + est l'operation d'addition, et le - est le signe du nombre 3.

Visualisation sur la droite graduee

L'addition se visualise comme un deplacement sur la droite graduee :

  • Ajouter un nombre positif = se deplacer vers la droite
  • Ajouter un nombre negatif = se deplacer vers la gauche
   

Cas particuliers

- La somme de deux nombres opposes est toujours nulle : a + (-a) = 0.
- Ajouter 0 ne change pas le nombre : a + 0 = a.

Soustraction de nombres relatifs

Soustraire un nombre, c'est ajouter son oppose.
a - b = a + (-b)

Cette regle est fondamentale : elle permet de transformer toute soustraction en addition, et donc d'utiliser les regles d'addition que l'on connait deja.

Pour calculer a - b :
1. Ecrire l'oppose de b (changer son signe).
2. Remplacer la soustraction par une addition de cet oppose.
3. Appliquer les regles de l'addition.
(+5) - (+3) = (+5) + (-3) = +2
(+2) - (+7) = (+2) + (-7) = -5
(-4) - (-6) = (-4) + (+6) = +2
(-3) - (+5) = (-3) + (-5) = -8
L'erreur classique est d'oublier de changer le signe du nombre qu'on soustrait. Dans (-4) - (-6), on ne soustrait pas 6 : on ajoute l'oppose de (-6), c'est-a-dire (+6).

Pourquoi ca marche ?

Sur la droite graduee, soustraire (+3) revient a reculer de 3 unites vers la gauche. Or, avancer de (-3) signifie aussi aller vers la gauche de 3 unites. Soustraire un nombre et ajouter son oppose produisent le meme deplacement !

Simplification d'ecriture

Quand on enchaine additions et soustractions, on peut simplifier l'ecriture en supprimant les parentheses :

(+5) - (+3) + (-2) - (-4)
= (+5) + (-3) + (-2) + (+4)
= 5 - 3 - 2 + 4  (ecriture simplifiee)
= +4

Multiplication de nombres relatifs

Regle des signes

Le produit de deux nombres relatifs est :
-- positif si les deux facteurs sont de meme signe ;
-- negatif si les deux facteurs sont de signes contraires.

On peut retenir cette regle grace au tableau des signes :

x+-
++-
--+
Pour multiplier deux nombres relatifs :
1. Determiner le signe du produit (tableau des signes).
2. Multiplier les valeurs absolues.
3. Mettre le signe devant le resultat.
(+3) x (+4) = +12  (meme signe -> +, 3x4=12)
(-3) x (-4) = +12  (meme signe -> +, 3x4=12)
(+3) x (-4) = -12  (signes differents -> -, 3x4=12)
(-3) x (+4) = -12  (signes differents -> -, 3x4=12)

Illustration geometrique

On peut visualiser la multiplication comme l'aire d'un rectangle dans un repere. Le signe du produit correspond au quadrant dans lequel se trouve le rectangle.

   

Produit de plusieurs facteurs

Dans un produit de plusieurs facteurs :
-- si le nombre de facteurs negatifs est pair, le produit est positif ;
-- si le nombre de facteurs negatifs est impair, le produit est negatif.
(-2) x (+3) x (-4) = +24  (2 facteurs negatifs, pair -> +)
(-1) x (-2) x (-3) = -6  (3 facteurs negatifs, impair -> -)

Puissances de nombres negatifs

Pour tout nombre negatif a et tout entier naturel n :
-- si n est pair, alors an est positif ;
-- si n est impair, alors an est negatif.
(-3)² = (-3) x (-3) = +9
(-2)³ = (-2) x (-2) x (-2) = -8
(-1)&sup4; = +1
Attention a la difference entre (-3)² et -3² !
(-3)² = (-3) x (-3) = +9  (on eleve -3 au carre)
-3² = -(3 x 3) = -9  (on eleve 3 au carre, puis on met le signe -)

Division de nombres relatifs

Regle des signes pour la division

La regle des signes pour la division est la meme que pour la multiplication :
-- Meme signe -> quotient positif
-- Signes contraires -> quotient negatif
:+-
++-
--+
Pour diviser deux nombres relatifs :
1. Determiner le signe du quotient (meme regle que la multiplication).
2. Diviser les valeurs absolues.
3. Mettre le signe devant le resultat.
(+12) : (+4) = +3
(-12) : (-4) = +3
(+12) : (-4) = -3
(-12) : (+4) = -3

Ecriture fractionnaire

Le quotient de a par b (avec b != 0) s'ecrit aussi sous forme de fraction : ab. Les trois ecritures suivantes sont egales : -ab = a-b = -ab
-153 = 15-3 = -153 = -5
On ne divise jamais par zero ! L'expression a0 n'a pas de sens.

Lien avec la multiplication

Diviser par un nombre non nul, c'est multiplier par son inverse :
a : b = a x 1b  (pour b != 0)
(-20) : (+4) = (-20) x 14 = -5
On peut verifier : (-5) x (+4) = -20

Exercice 1 -- Calculs d'additions

Calculer :

a) (+7) + (-3)  ;  b) (-5) + (-8)  ;  c) (+4) + (+9)  ;  d) (-6) + (+11)

Correction :

a) (+7) + (-3) : signes contraires, |7| > |3|, donc signe + et 7 - 3 = 4. Resultat : +4

b) (-5) + (-8) : meme signe -, on additionne 5 + 8 = 13. Resultat : -13

c) (+4) + (+9) : meme signe +, on additionne 4 + 9 = 13. Resultat : +13

d) (-6) + (+11) : signes contraires, |11| > |6|, donc signe + et 11 - 6 = 5. Resultat : +5

Exercice 3 -- Multiplications et divisions

Calculer :

a) (-5) x (+4)  ;  b) (-3) x (-7)  ;  c) (+18) : (-6)  ;  d) (-24) : (-8)

Correction :

a) (-5) x (+4) : signes differents -> negatif. 5 x 4 = 20. Resultat : -20

b) (-3) x (-7) : meme signe -> positif. 3 x 7 = 21. Resultat : +21

c) (+18) : (-6) : signes differents -> negatif. 18 : 6 = 3. Resultat : -3

Exercice 4 -- Enchainements d'operations

Calculer en respectant les priorites :

a) (-3) + (+5) x (-2)

b) (-4) x (+3) - (-6)

c) [(+8) - (-2)] x (-3)

Correction :

a) (-3) + (+5) x (-2)
= (-3) + (-10)  (la multiplication est prioritaire : (+5) x (-2) = -10)
= -13

b) (-4) x (+3) - (-6)
= (-12) - (-6)  (multiplication d'abord : (-4) x (+3) = -12)
= (-12) + (+6) = -6

c) [(+8) - (-2)] x (-3)
= [(+8) + (+2)] x (-3)  (les crochets d'abord)
= (+10) x (-3) = -30

Exercice 5 -- Temperatures

Probleme : La temperature a Strasbourg est de -4 C le matin. Elle augmente de 7 C a midi, puis baisse de 9 C le soir. Quelle est la temperature le soir ?

Correction :

Temperature le matin : -4 C

A midi : (-4) + (+7) = +3 C  (augmentation = addition d'un positif)

Le soir : (+3) + (-9) = -6 C  (baisse = addition d'un negatif)

La temperature le soir est de -6 C.

Exercice 6 -- Compte bancaire

Probleme : Le solde d'un compte bancaire est de +150 euros. On effectue les operations suivantes : un retrait de 200 euros, un depot de 75 euros, un retrait de 50 euros. Quel est le solde final ?

Correction :

Solde initial : +150

Apres le retrait de 200 : (+150) + (-200) = -50

Apres le depot de 75 : (-50) + (+75) = +25

Apres le retrait de 50 : (+25) + (-50) = -25

Le solde final est de -25 euros (le compte est a decouvert).
